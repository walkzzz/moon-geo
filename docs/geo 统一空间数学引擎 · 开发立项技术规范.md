## 0. 20年愿景与战略定位

### 0.1 终极愿景

20 年内，将 geo 建设为**范畴化空间数学范式的定义者**：以范畴论为最底层抽象，统一全空间、全维度、全数域、全拓扑形态的几何计算，向下扎根数学公理且经形式化验证，向上支撑 CAD/GIS/仿真/机器人/AR-VR/数字孪生/量子计算等全行业空间计算需求，成为开源学术生态中空间数学的基础设施。

### 0.2 四纪元总览

| 纪元 | 年份 | 月份 | 版本号区间 | 主题 | 愿景验收 |
|------|------|------|-----------|------|---------|
| 纪元一·奠基 | 2026-2031 | 0-60 | `0.1.x.y` | 工程可用 + 数学完备 | 工业级可用，复射影大一统验证 |
| 纪元二·完备 | 2031-2036 | 60-120 | `0.2.x.y` | 数学大一统 + 生态建立 | 范畴化抽象落地，核心定理形式化，OGC 符合 |
| 纪元三·融合 | 2036-2041 | 120-180 | `0.3.x.y` | 前沿融合 + 标准主导 | AI-可微几何、量子几何、数字孪生底座、标准主导 |
| 纪元四·范式 | 2041-2046 | 180-240 | `0.4.x.y` | 范式定义 + 终极愿景 | 范畴-量子统一范式，形式化完备，升 `1.0.0.0` |

### 0.3 战略原则（开源学术驱动）

1. **开源优先**：核心永久开源（Apache-2.0），无双轨闭源核心；企业增值服务仅限托管/支持/集成，不锁核心
2. **学术驱动**：以数学完备性与形式化验证为最高准则，工程性能服从数学正确性
3. **标准参与**：从 OGC/ISO 标准符合者逐步成为标准制定参与者与主导者
4. **生态基础设施**：不做终端产品，做他人产品的底座；与竞品错位互补而非正面替代
5. **终身兼容**：核心 Trait 第一阶段冻结后永久稳定，20 年内无破坏性变更

### 0.4 与竞品长期定位

| 竞品 | 领域 | 与 geo 的长期关系 |
|------|------|------------------|

| OpenCASCADE | C++ CAD 内核 | geo 拓扑层对标但代数层更通用（复/射影），CAD 领域做适配层而非替代内核 |

| Lean4 / Coq 几何库 | 形式化 | geo 纪元二起与形式化社区协同，几何定理库双向桥接 |

### 1.1 九层单向依赖架构

采用「洋葱型」分层架构，内层越稳定、抽象度越高，外层越灵活、业务性越强；上层只能依赖下层，下层完全不感知上层，保证核心架构终身不重构。

### 1.2 核心设计原则

1. **抽象分层**：数学层、拓扑层、算法层、业务层严格分离，单向无环依赖。
2. **Trait驱动**：每一层用统一Trait定义行为，新增图元/空间类型只需实现对应Trait，所有算法自动复用。
3. **内外分离**：内核保留完整数学完备性（复数、射影、高维），对外暴露极简实数域工程API，用户无感知底层复杂度。
4. **终身兼容**：核心抽象Trait第一阶段结束后永久冻结，新增能力只扩展、不修改原有接口，无破坏性变更。
5. **开闭统一**：代数给形状，拓扑定开闭，开闭定体面；同一几何图元通过裁剪信息区分开放面/封闭壳/实体。

## 2. 分层详细设计

### 2.1 基础工具层 `geo::util`

**职责**：全库数值基础，零几何语义，完全独立可编译。 **依赖**：无

#### 核心Trait

```
// 浮点近似相等：所有几何比较的基准
pub trait ApproxEq {
  fn approx_eq(&self, other: &Self, tol: F64) -> Bool
  fn approx_zero(&self, tol: F64) -> Bool
}

// 数值通用扩展
pub trait NumExt {
  fn sq(&self) -> Self
  fn clamp(&self, min: Self, max: Self) -> Self
  fn lerp(&self, other: &Self, t: F64) -> Self
}

// 数域抽象：实数、复数统一接口
pub trait Field: Add + Sub + Mul + Div + NumExt + ApproxEq + Clone {
  fn zero() -> Self
  fn one() -> Self
  fn abs(&self) -> F64
}
```

#### 核心基础类型

| 类型   | 构造方式                            | 核心方法                                                     |
| ------ | ----------------------------------- | ------------------------------------------------------------ |
| `Cpx`  | `Cpx::new(re: F64, im: F64)`        | `conj()` 共轭、`norm()` 模长、`norm_sq()` 模平方、`inv()` 逆 |
| `Vec2` | `Vec2::new(x: F64, y: F64)`         | `len()` 长度、`dot()` 点积、`cross()` 叉积、`normalize()` 单位化 |
| `Vec3` | `Vec3::new(x: F64, y: F64, z: F64)` | 同 Vec2，新增三维叉积                                        |
| `Mat3` | `Mat3::identity()`                  | `det()` 行列式、`inv()` 逆、`transpose()` 转置、`mul_vec()` 乘向量 |
| `Mat4` | `Mat4::identity()`                  | 同 Mat3，新增齐次变换构造                                    |
| `Quat` | `Quat::identity()`                  | `from_axis_angle()` 轴角构造、`from_euler()` 欧拉角构造、`slerp()` 球面插值、`to_mat4()` 转矩阵 |

#### 全局常量

```
pub const EPS: F64 = 1e-8        // 默认浮点计算公差
pub const MIN_POSITIVE: F64 = 1e-12  // 最小正数值
```

### 2.2 代数拓扑内核 `geo::atop`

**职责**：定义最普适的空间抽象，所有空间类型都是它的特例，实现真正的数学底层大一统。 **依赖**：`geo::util`

#### 核心Trait（终身冻结）

```
// 最底层：拓扑空间抽象
pub trait TopologicalSpace {
  type Point
  type OpenSet
  /// 邻域判定：点是否在开集内
  fn is_in_neighborhood(p: &Self::Point, set: &Self::OpenSet) -> Bool
}

// 流形空间：局部同胚于欧氏空间的拓扑空间
pub trait Manifold: TopologicalSpace {
  type Dim: Dim
  type Field: Field
  /// 局部坐标映射：流形点映射到切空间欧氏坐标
  fn local_chart(p: &Self::Point) -> Vec<Self::Dim, Self::Field>
}

// 度量空间：有距离定义的拓扑空间
pub trait MetricSpace: TopologicalSpace {
  fn distance(a: &Self::Point, b: &Self::Point) -> Self::Field
}
```

#### 远期扩展能力

- 非欧空间支持：黎曼流形、双曲空间、球面空间
- 奇异空间、非流形空间的统一抽象
- 同调群、上同调、持久同调计算

### 2.3 空间抽象层 `geo::space`

**职责**：统一所有空间类型的坐标、距离、变换三要素，实现矢量/栅格、实/复、欧氏/射影/时空的大一统。 **依赖**：`geo::util` + `geo::atop`

#### 核心Trait

```
pub trait Space: MetricSpace + Manifold {
  /// 维度标记
  type Dim: Dim
  /// 数域类型
  type Field: Field
  /// 原生坐标点类型
  type Point: Clone + ApproxEq
  /// 空间原生变换类型
  type Transform: Clone

  /// 两点距离
  fn distance(a: &Self::Point, b: &Self::Point) -> Self::Field
  /// 应用变换到点
  fn transform_point(p: &Self::Point, t: &Self::Transform) -> Self::Point
  /// 坐标插值
  fn lerp_point(a: &Self::Point, b: &Self::Point, t: F64) -> Self::Point
}

pub trait Dim { fn value() -> Int }
pub struct Dim2; impl Dim for Dim2 { fn value() -> Int { 2 } }
pub struct Dim3; impl Dim for Dim3 { fn value() -> Int { 3 } }
pub struct Dim4; impl Dim for Dim4 { fn value() -> Int { 4 } }
```

#### 空间映射Trait（跨空间转换标准）

```
pub trait SpaceMap<Src: Space, Dst: Space> {
  fn map_point(p: &Src::Point) -> Dst::Point
  fn unmap_point(p: &Dst::Point) -> Src::Point
  fn mapping_error() -> F64
}
```

#### 全量空间类型规划

| 空间类型     | 维度          | 数域 | 核心用途                 | 落地阶段 |
| ------------ | ------------- | ---- | ------------------------ | -------- |
| `Euclid2`    | 2D            | 实数 | 平面矢量几何（默认）     | 第一阶段 |
| `Euclid3`    | 3D            | 实数 | 三维实体几何（默认）     | 第一阶段 |
| `Complex2`   | 2D            | 复数 | 复平面几何、代数完备求解 | 第二阶段 |
| `Proj3`      | 3D齐次        | 实数 | 透视变换、无穷远点统一   | 第二阶段 |
| `Raster2`    | 2D离散        | 实数 | 图像、像素栅格           | 第二阶段 |
| `Raster3`    | 3D离散        | 实数 | 体素、三维栅格           | 第三阶段 |
| `Spacetime3` | 4D（3空+1时） | 实数 | 动态轨迹、时序几何       | 第四阶段 |
| `Spherical3` | 3D球面        | 实数 | 球面几何、大地测量       | 第四阶段 |

1. **球极投影**：复平面 ↔ 三维单位球面，保圆性映射
2. **栅格-矢量**：栅格 ↔ 矢量空间，采样/插值双向转换

### 2.4 代数几何层 `geo::alg`

**职责**：所有几何图元的数学本质，一个Trait统一所有点/线/曲线/曲面/超曲面。 **依赖**：`geo::util` + `geo::space`

#### 核心统一Trait

```
pub trait Geo {
  /// 所属空间
  type Space: Space

  /// 图元分类标识
  fn kind(&self) -> GeoKind
  /// 生成轴对齐包围盒
  fn bbox(&self) -> impl Bv
  /// 应用空间变换，返回新图元
  fn transform(&self, t: &<Self::Space as Space>::Transform) -> Result<Self, GeoError>
  /// 代数求交，返回交点集合
  fn intersect(&self, other: &impl Geo<Space = Self::Space>) -> Vec<<Self::Space as Space>::Point>
  /// 点对本图元的幂（圆幂/球幂大一统推广）
  fn power(&self, p: &<Self::Space as Space>::Point) -> <Self::Space as Space>::Field
  /// 代数包含判定
  fn contains(&self, p: &<Self::Space as Space>::Point) -> Bool
  /// 判别式：判断退化、分类图元类型
  fn discriminant(&self) -> <Self::Space as Space>::Field
  /// 是否为退化图元
  fn is_degenerate(&self) -> Bool { self.discriminant().approx_zero() }
}

pub enum GeoKind {
  Point, Line, Conic, Plane, Quadric, Cubic, Higher
}
```

#### 变换统一Trait

```
pub trait Transform {
  type Space: Space
  /// 合并变换：先应用self，再应用other
  fn then(&self, other: &Self) -> Self
  /// 逆变换
  fn inverse(&self) -> Result<Self, GeoError>
  /// 恒等变换
  fn identity() -> Self
}
```

#### 核心图元实现

| 结构体        | 空间      | 构造函数                              | 说明                                     |
| ------------- | --------- | ------------------------------------- | ---------------------------------------- |
| `Pt2` / `Pt3` | 2D/3D欧氏 | `Pt3::new(x,y,z)`                     | 点                                       |
| `Line2`       | 2D欧氏    | `Line2::from_points(p1,p2)`           | 直线                                     |
| `Circle`      | 2D欧氏    | `Circle::new(center, r)`              | 圆（圆锥曲线特例）                       |
| `Conic2`      | 2D欧氏    | `Conic2::new(coeffs)`                 | 统一圆锥曲线，退化得到圆/椭圆/抛物/双曲  |
| `Plane3`      | 3D欧氏    | `Plane3::from_normal(center, normal)` | 平面                                     |
| `Sphere`      | 3D欧氏    | `Sphere::new(center, r)`              | 球面                                     |
| `Quad3`       | 3D欧氏    | `Quad3::new(coeffs)`                  | 统一二次曲面，退化得到球面/椭球/马鞍面等 |

### 2.6 拓扑边界层 `geo::brep`

**职责**：给代数几何图元附加裁剪、邻接、定向信息，区分开放面/封闭壳/实体。 **依赖**：`geo::alg` + `geo::bv`

## 6. 工程保障体系

### 6.1 质量保障

1. **单元测试**：每层独立单测，核心数学定理100%用例覆盖
2. **基准对标**：所有算法与CGAL、ArcGIS、OpenCASCADE工业级基准对比
3. **回归测试**：每个版本全量回归，保留历史用例
4. **模糊测试**：随机生成几何数据，挖掘边界崩溃
5. **数值稳定性测试**：极端边界、退化场景全覆盖

### 6.2 性能保障

1. 标准性能测试集：点集凸包、实体布尔、海量相交检测
2. 每个版本发布性能报告，监控性能退化
3. 分层加速：包围体粗筛 + 代数精算，兼顾性能与精度

### 6.3 兼容性保障

1. **语义化版本**：主版本号破坏性变更，次版本号新增能力，修订号修复bug
2. **核心Trait冻结**：第一阶段结束后核心抽象永久冻结
3. **新增能力子Trait化**：不修改原有接口，通过子Trait扩展
4. **废弃API保留**：废弃API保留至少2个次版本周期，提供迁移指引

### 6.4 文档体系

1. API文档：每个公开接口带注释、示例
2. 数学原理文档：圆幂、二次曲面、复射影等底层理论说明
3. 开发规范：新增图元、新增算法的开发流程与规范
4. 行业场景示例：CAD、GIS、仿真等领域使用案例

## 7. 命名与编码规范

### 7.1 命名规则

| 元素              | 规则                         | 示例                             |
| ----------------- | ---------------------------- | -------------------------------- |
| 结构体/枚举/Trait | 大驼峰，短名词，领域通用缩写 | `Pt3`, `Quad3`, `Geo`, `Topo`    |
| 函数/方法         | 小蛇形，动词开头             | `new`, `is_closed`, `transform`  |
| 模块/文件         | 小蛇形                       | `quadric.mbt`, `topo_relate.mbt` |
| 常量              | 全大写下划线                 | `EPS`, `MIN_POSITIVE`            |

### 7.2 编码约定

1. **不可变原则**：几何/拓扑对象默认不可变，修改操作返回新对象
2. **错误处理**：所有可能失败的操作返回 `Result<T, GeoError>`，禁止panic
3. **公差原则**：所有几何比较使用近似相等，禁止直接 `==` 比较浮点数
4. **单向依赖**：严格遵守分层依赖方向，禁止反向依赖
5. **泛型优先**：算法优先基于Trait泛型实现，避免重复代码

## 13. 版本号规约 `0.x.y.z`

### 13.1 四段式语义

| 段 | 名称 | 语义 | 取值 |
|----|------|------|------|
| 第1段 | 主版本 | 项目大版本；20 年规划期内保持 `0`，终极愿景达成升 `1` | `0` → `1` |
| 第2段 `x` | 纪元号 | 纪元编号 | `1`-`4` |
| 第3段 `y` | 阶段号 | 纪元内阶段编号 | `1`-`N` |
| 第4段 `z` | 迭代号 | 阶段内迭代（月/季度）递增，含功能与修复 | `0`-`N` |

### 13.2 示例

- `0.1.1.0`：纪元一·阶段一·首次迭代（2026 初）
- `0.1.3.5`：纪元一·阶段三·第 6 次迭代
- `0.2.1.0`：纪元二·阶段一·首次迭代（2031）
- `1.0.0.0`：终极愿景达成（2046）

### 13.3 兼容性语义

- `x` 递增（纪元跃迁）：允许 Level 2/3 API 变更，Level 1 保持兼容
- `y` 递增（阶段递进）：Level 1/2 保持兼容，新增能力
- `z` 递增（迭代）：全 Level 兼容，仅修复与增量实现
- 第1段 `0` 期间：Level 1 API 在核心 Trait 冻结后稳定，此前允许调整

### 13.4 与 SemVer 关系

`0.x.y.z` 兼容 SemVer：`major=0, minor=x, patch=y`，`z` 视为预发布迭代标识。
